# TC-06 — Budget and admission governance

TC-06 adds a deterministic gate before governed LLM dispatch. It checks recovery and reusable reasoning, then the exact TC-05 capability, then explicit LLM necessity, internal task budget, role allocation, and configured Advisor review reserve. Only `ADMIT` creates an atomic `RESERVED` execution reservation and a verifiable dispatch permit.

Budgets are explicit task policy, not account quota. Context bytes are measured; token values remain estimates with a named method; account quota remains `NOT_AVAILABLE`. Role allocations partition the task budget and are never added to it. Released reservations do not count as consumption; uncertain reservations retain their reservation and prohibit automatic retry.

The material reasoning fingerprint excludes execution identity while retaining revision, authority, blockers, protected baselines, source evidence, objective, scope, and complete inputs. Contractually independent review bypasses reuse but still requires admission. No policy may prune context, reduce output, enable paid fallback, or change authority.
